# DPGF dans les pièces écrites — plan de réalisation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** importer des DPGF (Excel ou PDF) à côté des CCTP, les consulter, les chercher et voir leurs lignes sous chaque article du CCTP, au bureau et en visite hors ligne.

**Architecture:** toute la lecture est pure dans `dpgfLogique.js` (Excel → grille de cases, PDF → lignes de cases positionnées), testée sur tableaux inventés ; le lien CCTP ↔ DPGF se calcule à l'affichage (même lot, même numéro). Une table `pieces_dpgf_lignes` (migration 073) ; `pieces_ecrites.type` accepte `dpgf`. L'écran réutilise le module existant : tuile par lot, `LecteurDpgf` sur le modèle de `LecteurCctp`, recherche étendue.

**Tech Stack:** React 19, Supabase, pdf.js (déjà là), SheetJS `xlsx` (déjà dans les dépendances, chargé à la demande), `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-19-dpgf-design.md`

## Global Constraints

### Task 2 : Base (migration 073) et données

**Files:** Create `supabase/migrations/073_dpgf.sql` ; Modify `piecesDonnees.js`, `lecturePdf.js`.

**Interfaces — Produces :** `listerPieces(affaireId) → { disponible, dpgfDisponible, pieces, articles, lignes }` ; `enregistrerPiece({ affaireId, lotId, type: 'cctp' | 'dpgf', lu, nomFichier, titre })` (`lu` : `{ lot, indice, nbPages, articles }` pour un CCTP, `{ lot, indice, nbPages, lignes }` pour un DPGF) ; `piecesPourConsultation` et `garderCopie` portent `lignes`.

- [ ] Migration rejouable :
  ```sql
  alter table pieces_ecrites drop constraint if exists pieces_ecrites_type_check;
  alter table pieces_ecrites add constraint pieces_ecrites_type_check check (type in ('cctp', 'dpgf'));
  create table if not exists pieces_dpgf_lignes (
    id uuid primary key default gen_random_uuid(),
    piece_id uuid not null references pieces_ecrites(id) on delete cascade,
    affaire_id uuid not null references affaires(id) on delete cascade,
    ordre integer not null, numero text, article text, niveau integer,
    designation text not null default '', unite text, quantite numeric,
    quantite_texte text, titre boolean not null default false, page integer
  );
  ```
  index `(affaire_id)` et `(piece_id, ordre)`, puis le bloc de règles de la 061 pour `pieces_dpgf_lignes` ; `notify pgrst, 'reload schema'`.
- [ ] `listerPieces` : lit `pieces_dpgf_lignes` en parallèle ; table absente (`PGRST205` / `42P01`) → `lignes: []`, `dpgfDisponible: false`. Chaque ligne porte `lot_id` de sa pièce.
